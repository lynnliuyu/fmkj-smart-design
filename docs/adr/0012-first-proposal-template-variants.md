# 0012 首次提案增加生活体验与空间设计四套模板

Status: Accepted
Date: 2026-10-23

## Context

用户上传另一家 55 页全屋智能设计方案，要求网上参考优质提案，提供内容更丰富、适合首次设计报价、与现有项目搭配并一键生成的 PDF 模板。用户明确选择优先突出「生活体验与设计感」。首轮为暖境与序境，后续补充自然疗愈与光影艺廊两套，使首次沟通有四种气质可选。

ADR 0011 限制的是上一轮默认报价只换外观；本轮明确新增独立首次提案，不反转已选定的默认报价版式，也不把“内容丰富”解释为可以虚构售后与工期承诺。

## Decision

- 在客户交付页增加四套首次提案和一个生成动作；保留原报价与原方案导出。
- 新模板直接消费 ProjectDeliverySnapshot、既有渲染后的楼层图和 DocumentBrand，复用 outputDelivery 固定版本出口。不增加客户采购计算、另一套数据库读写、产品采集或报价金额来源。
- 四套在封面、图像、内容排列上有差异，优先说明生活体验，再对应空间、选配、预算、明细、图纸与沟通确认。
- 产品与场景的核验和确认状态均保留；费用取已保存的最终单价、小计及总额。分房汇总只用于阅读明细，不反推或覆盖报价。
- 图片清楚区分 AI 意向示意与项目原图。新增沟通步骤和待约定事项不构成服务承诺，不写固定质保、付款比例、工期与兼容结论。
- 新样式作用域限于首次提案。打印时只挂载所选模板，和既有方案正文隔离；打印完成或切项目后清理，避免下一次打印混入。
- 独立样例采用虚构数据，通过同一生产组件实际导出并逐页检查；不写客户数据库，不生成真实客户交付。

## Consequences

用户可以用同一固定版本切换四套客户提案，金额和设计资料保持一致。客户没有场景、图片、报价或品牌联系方式时，保持真实的空状态或省略相应可选项，不补造。
