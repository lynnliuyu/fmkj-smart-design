# 0009 本机图片存储与同坐标图纸对照

Status: Accepted
Date: 2026-10-16

## Context

用户选定优化 2 与 4：解决大图片重复写入 localStorage 导致本机缓存失败，并在工作台直接对照布局、灯光、开关图。沿用 ADR 0004 的来源指纹与 affine 配准、ADR 0006—0008 的报价、固定交付和图标规则。

## Decision

- 本机草稿存储 module 提供异步 read / write interface；IndexedDB adapter 将图片与文字分开，按完整 data URL 的 SHA-256 去重，同图跨楼层兼容字段、备份复用；解包恢复原字符串，校准指纹不变。源图资产不使用 LRU 删除。
- 图片和文字在同一事务提交，同项目写入排队；失败保留上次成功记录并明确提示。旧缓存只在迁移成功且旧字符串未被其他页面改写后清除；失败保留并尽量读取旧稿。缺图、损坏或未知版本不能静默变成空方案。
- IndexedDB 只保存本机副本，不能替代数据库保存和 JSON 备份。数据库与可携带 JSON 继续保存完整图片。报价页加点使用同一异步 interface，同页面连续添加按序处理。
- **图纸对照 / Reference Drawing** 按楼层保存 references.lighting / switch；布局始终是工程净底，不复制布局图片。复用既有配准 module 的校验，在固定工程画布中用逆矩阵显示；切图不改点位坐标、缩放和平移。
- 普通图片必须选三组分散、非共线的同一建筑角点，横纵跨度各至少 50%。来源指纹过期或配准非法时明确报错并停止该图上的布点。CAD 图纸包必须依据已核对的原 DWG 指纹、视口冻结图层和共同 WCS 窗口准备，不能凭同像素尺寸声明已配准。
- 明确裁切工程净底时同步转换对照图矩阵与来源锚点，不能安全转换则整次拒绝。配准期间草稿变化，同样拒绝覆盖。
- 对照图辅助设计核对，不替代客户展示底图，不增加报价计算或客户导出来源。旧确认版本、固定交付不回写，同一安装点不增加设备件数。

## Evidence

验收和实际项目状态见 Plan 027。示例项目灯光 / 开关图按同一 CAD 窗口输出 3000 × 2127，开关密集内容采用原生 PDF，保留连线和文字，原 DWG 未改动。
