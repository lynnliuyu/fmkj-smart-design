# 0003 工作台与 CAD 使用同源设备图形

Status: Accepted
Date: 2026-10-14

## Context

工作台原有 PNG 素材与 Cadcraft 原生图块外观不同，客户不清楚哪套作为最终图例。新增无线 AC 与 PoE 交换机还存在同名误匹配：AC 会与暖通混淆，PoE/英文 Switch 可能被识别为 AP 或智能开关。

## Decision

- `lib/point-device-symbols.mjs` 保存纯设备几何与颜色，浏览器和本地 Node 桥接共用，不包含文件或网络操作。脚本从同一几何生成静态 SVG，Cadcraft 桥接生成原生图块。
- 工作台点位、图例与导出 PNG 统一读取生成的 SVG；旧设备 ID、旧 PNG 文件与 CAD 图块身份继续兼容。新增无线 AC 控制器与 PoE 交换机为全屋 Wi-Fi 独立类型。
- 最终交付以工作台出图为准。图标代表设备类别，方向/覆盖意图记在备注，不伪装成实测覆盖。输出清单保留未定位设备及所有设计备注。
- 产品匹配优先识别明确设备身份；PoE 只是供电/传输特征，不能单独决定图标。图标短码仅在完整查询时命中，避免 AC 等子串抢占语义。

## Consequences

维护一次几何即可同步两边，避免独立改图导致漂移。离线工具必须同时携带共享模块。用户在 CAD 中自行改变颜色/旋转/尺寸仍属 CAD 视图调整，当前文件回传仅更新位置；最终图示及业务说明以工作台数据为准。
