# 0011 报价单客户版式换成模版2 风格（只换外观）

Status: Accepted
Date: 2026-10-22

## Context

客户报价 PDF 的版式此前由 `components/quotes/quote-builder.tsx` 内联的 `QuotePrintDocument` 与 `app/globals.css` 的 `@media print` 段落决定。[DESIGN.md](../../DESIGN.md) 把客户交付内容（报价单 A4 排版、方案 PDF、交付图）列为不随界面调整改动的部分。

2026-10-22 用户先看了四款**独立演示模版**（`output/quote-templates-demo/`，虚构示例数据、未接入系统、不改动线上导出），选定「模版2 · 现代简约」为默认风格，并要求接进系统现有导出。用户就接入范围做了两个明确选择：

- **只换外观**：客户看到的明细、条款、金额口径与字段一个都不变。
- **直接替换**：不留"旧版式/新版式"运行时开关。

ADR 0007 记录过「PDFCraft 母版仍是模拟试排，没有在本轮擅自替换现有导出」。本轮替换来自用户的明确要求，符合"不擅自替换"的边界。

## Decision

- 报价 PDF 采用模版2 的视觉语言：品牌页头（logo + 公司名 + 联系方式/地址，遵循「填了才印、留空不留白」）、标题区、信息区与大字应收合计、**每个分组一张卡片**的明细、费用构成 / 报价说明 / 客户确认签字 / 联系我们收尾；楼层点位图保持每层一页、整页居中的既有分页行为。
- 排版仍是**流式**：沿用既有 `@page { size: A4; margin: 10mm }` 与 190mm 版心，不引入固定高度分页骨架（演示稿的 `.page` 结构不搬进应用）。强调色 `#2C4A6B` 以 scoped 变量只作用于 `.quote-document`。
- 客户可见内容与口径不变：列语义（产品/规格/房间/数量/单价/总价）、未核验与配套未计入说明（ADR 0006）、金额、条款、签字区一律照旧；**不新增**「质保与售后」「交付与施工流程」等栏目——用户此次未采纳该方案，若以后要加，文案来源与是否后台可配需另议。
- 打印文档抽成独立组件 `components/quotes/quote-print-document.tsx`（props 与原来一致），导出链路（先保存本页报价 → 同一固定交付版本 → `window.print()`）不变，不新增数据请求、第二条出图来源或客户端采购计算。
- 旧版式的结构与样式留在版本记录中；需要回退时按提交回退，不保留运行时开关。

## Consequences

- 客户拿到的报价单是新版式；报价 PDF 与方案 PDF 仍共用 `@page`、`.document-brand`、`.document-contact`，因此**方案 PDF 版式不受影响**。
- 流式排版下，分组卡片跨页时按卡片整体避断；超长分组仍可能顺延到下一页，这与替换前的行为一致。
- 新增测试覆盖打印文档的结构、字段来源与文案口径（含"不含演示稿字样"），视觉验收以独立预览（SSR + 无头浏览器出 A4 PDF/PNG）为准。
- 演示目录 `output/quote-templates-demo/` 仍是独立的模版实验场，不参与线上导出；以后再试新版式继续在那里做，验证通过后按本 ADR 的方式接入。
