# 0008 所有客户共用底图规范、屏幕布点交互与固定出图规则

Status: Accepted
Date: 2026-10-15

## Context

用户要求后续客户都走同一套流程。单纯增加图片像素不扩大窗口里的房间；原工作台图标跟随画布放大时过大，Plan 023 又将符号缩成约 7—12 屏幕像素，开关键数无法辨认。实际样张存在几个相距很近或完全重合的安装点，固定比例无法同时满足整屋显示、逐个选中和局部布点。

本决策替代 Plan 023 的编辑图标缩放规定，保留 ADR 0002 的 CAD 坐标、ADR 0003 的设备图形和 ADR 0005—0007 的保存 / 固定交付语义。

## Decision

- 工程净底准备与导出图形区域统一长边 3000 px，短边等比计算。2026-10-15 用户补充确认：新净底去除建筑有效范围以外的空纸，横纵分别保留有效范围约 3% 安全边距；内部白色房间不裁，原图对照资料保留完整图框。先定范围再统一像素，不拉伸。图片分辨率和浏览器显示比例分别表达。
- 布局、灯光、开关图必须先完成配准，再共用同一裁切范围；不能逐张独立紧裁后假定已经对齐。CAD 净底清单记录 `selectionWindow`、像素 `crop` 和裁切后的 `window`；`--crop-frame` 仅接受同一原图、同一原始坐标窗口的清单，容不下图形时拒绝而不截断。不同位置的原图页先配准，不能直接复用。
- 已有底图通过“高级工具 → 整理底图留白”明确操作，作为一次本机草稿编辑：同步图片、已定位点位的百分比、CAD 窗口、风格校准矩阵 / 原锚点与工程展示偏移。实际 CAD 安装位置与风格图中的安装位置保持一致，SKU、点位确认状态与场景引用不变。外围有安装点 / 校准锚点、校准已失效或草稿在处理期间变化时，整次拒绝；不夹取坐标或静默删点。
- 操作前沿用本机备份出口保存原稿；缓存空间不足时明确备份仅当前页面有效，应在关闭前下载。整理后仍需“保存草稿”写数据库。独立的风格图片保留，通过新矩阵保持原校准，不伪称已经裁切风格图；旧确认版本与固定交付资料不回写。
- 所有项目使用同一编辑行为：图标为 32 CSS px，交互区域 44 CSS px，通过补偿画布缩放保持清晰。既有设备几何和颜色不改，不添加每个客户专属的比例系数。
- 当前视图里交互范围重叠的点位形成临时**显示分组**，显示中性叠层符号与数量。组可跨设备类型，不能按组图案推断产品或设备身份。打开后列出每个点的编号、名称、房间与原图标，支持逐个选择和放大查看；缩放、窗口或筛选变化后重新计算，组的屏幕跨度受交互范围约束，避免链式相邻把整屋收成一组。
- 显示分组不合并安装点、产品件数或场景引用，不改坐标，不持久化到 plan。完全重合的点同样列出；当前选中 / 拖动点独立显示在顶层，保证可以移出重叠位置。
- “局部布点”将选中点（无选中时图纸中心）放大至工作视图，“查看全图”返回整体；从清单选中已定位点也会定位。相机操作只修改视口，不保存点位；只有明确拖动 / 方向键编辑才改变安装位置。
- 编号在选中、悬停或键盘聚焦时显示，完整信息保留在可访问名称和清单中。图标大小不新增客户级滑块，避免每份方案又形成一套设置。
- 客户 PNG / PDF 按统一输出尺寸排版，工程符号仍为 56 输出像素，商品圆图、展示偏移与引线沿用现有共享渲染器。编辑时的屏幕像素、分组和缩放不影响固定版本或报价。无需为本次编辑修复清除或重画客户出图缓存。

## Consequences

缩小整屋视图可以查分布和数量，靠得太近的开关通过组内列表或局部视图操作，不伪装成屏幕能在同一位置画出所有可读图标。显示分组数量只是当前筛选中已定位点位数，不是报价数量或采购结论。所有客户由相同代码自动适配，无数据库迁移，也不改历史交付资料。
