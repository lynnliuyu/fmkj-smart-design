# 0007 客户出口共用固定交付版本，编辑页只保存自己的资料

Status: Accepted
Date: 2026-10-15

## Context

工作台、报价页和方案页分别编排生成与导出；PNG、CSV 或 JSON 在当前资料预览中可直接下载，而打印会生成固定版本。用户难以判断发出的不同文件是否来自同一批数据。“保存点位后更新报价”又容易被理解为数据库报价已经保存。报价联动删除后，旧版本号没有完整返回编辑器，导致再次保存冲突。

本轮任务要求固定客户工作流、统一版本出口并减少工作台的重复入口；保留 ADR 0005 的不可变资料与 ADR 0006 的未核验客户报价。

## Decision

- 同一项目提供三个连续入口：点位设计、报价单、客户交付。点位页保存本页草稿，报价页保存本页报价；离开有未保存编辑的页面时，沿用现有保存 / 取消 / 不保存切换处理。交付页不代存其他标签页。
- 点位保存和项目默认型号变更，共用一个报价预览 module：读取明确的已保存 revision，检查项目与版本，再发布本机报价快照。阻塞时保留旧预览，切换项目后的迟到结果不覆盖当前页。空快照也发布，以清除已删除的点位来源行。数据库报价仍需在报价页保存。
- 客户交付的 PNG、方案 PDF、CSV 与完整 JSON，都先解析为固定 V 版本；报价 PDF 先保存本页报价，再使用同一固定交付出口。已选历史版本直接使用其原资料，不生成“最新”来替代它。只有明确“项目没有点位方案”且报价不含点位来源时，才保留纯报价 PDF。
- 工作台“草稿检查 PNG”保留在高级工具，使用当前编辑位置与已保存报价，供设计核对；文件和操作提示明确其草稿身份。它不代表恢复某个点位确认版当时的整套报价。
- 报价删除 / 同楼层房间调整联动点位时，要求来源 revision；服务端把新 revision 写入所有剩余来源行及快照，并返回编辑器。编辑器只确认本次提交的变更，保留保存期间新增的价格和其他编辑，不重复提交已经成功的删点操作。
- 房间变更不把其他楼层名称直接套在旧坐标上。跨楼层位置修改回到点位设计重新定位；来源房间整体重命名继续从点位设计完成。
- 工作台默认突出编辑与保存；助手导入、CAD 往返、底图、设计确认和备份收进高级工具。空项目与版本冲突时展开工具。项目资料页保留设计主入口，合同、工单、安装验收、售后、成员、现场图片集中在“执行与资料”，保持原直达地址和业务实现。

## Consequences

沿用既有数据库、图片与缓存 adapter，统一出口提高 locality 与 leverage，不新增另一套导出实现。删除无人调用的浏览器端旧报价计算、重复请求代码及无效果回调；迁移、历史解析和恢复路径保留。

PDFCraft 母版仍是模拟试排，没有在本轮擅自替换现有导出。仅更换照片不会改金额；固定版本的数据与图片归档不因界面精简而退回实时读取。
