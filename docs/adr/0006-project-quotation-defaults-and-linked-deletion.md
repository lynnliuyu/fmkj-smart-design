# 0006 默认型号可作未核验客户报价，项目换型独立，报价删除联动点位

Status: Accepted
Date: 2026-10-15

## Context

默认型号已经支持快速形成客户报价，但原文档将所有报价都等同于采购核验通过；项目中的统一换型又写入全局默认，造成跨项目影响。报价页删除来源行的实现会删除安装点，原有说明没有明确这一业务含义。

用户在本轮梳理中明确选择：允许默认型号直接进入客户报价并标注未核验；统一换型只影响当前项目；删除点位来源报价行同时删除关联安装点及相关场景引用。

## Decision

- **未核验报价**是可交给客户的报价表达，不是已核验采购结论。默认型号可以进入客户报价；涉及默认选型、规格 / 价格或布局未核实的行保留明确“未核验”标识和原因，保存、再次读取、完整交付及 PDF 不能丢掉该标识。默认型号不替用户确认点位、场景、参数或价格；预留点仍不计采购。
- 正式采购仍按明确选用、定位 / 设计确认、具体 SKU、适配参数、价格与必配用料核验。未核验报价与核验通过的采购不能仅用同一个“成功”结果表示。金额可报价不表示现场条件和供货规格已确认。
- 默认型号的客户报价不因未知轨道长度、配件数量或尚未选择配套型号而整单中断：只计已明确的设备及已核验的配套行，把未计入的配套范围与待核事项写入报价快照，并在报价页、两类 PDF 与 CSV 的统一核验标识中显示。不得虚构轨道米数或将未报配套表述为已经包含。具体已选 SKU 失效、单位 / 实体身份 / 已含范围冲突等数据错误仍阻止替换；明确选用后的正式采购仍要求用料完整。详见 Plan 026。
- “项目统一换型”是当前项目用于未指定产品点位的默认型号设置，按项目、设备类型及键数保存。只影响当前项目之后的报价预览，不改其他项目、明确关联产品的点位或历史交付。清除设置恢复本项目标准默认规则。
- 原全局默认记录不复制给所有项目；没有可靠的项目归属，不推断它属于哪个客户。保留原表供追溯，运行路径不再读取它作为项目覆盖设置。实际生效的项目型号需要按项目明确设置。
- 删除点位来源报价行或其区域时，保存报价在同一事务中删除关联安装点，移除场景中的对应引用并使受影响场景重新待复核。清空引用的场景按现有规则处理，不删除无关场景。不更改历史确认或交付快照。手动报价行不删除点位。
- 页面在执行删除前清楚告知联动范围，保存以点位 revision 检查并发；过期拒绝，不强行覆盖。取消尚未保存的删除不应改数据库。

## Consequences

本决策细化 ADR 0001 的点位来源报价和 ADR 0005 的完整版本语义，并替代 CONTEXT / Plan 020 中“未核验内容绝不能进入客户报价”的广义说法。严格采购条件继续有效。项目设置增加独立存储；迁移只增量建表，不批量重写已有报价、点位或全局设置。

实现与验收进度见 Plan 021；Accepted 表示业务选择已确定，不表示所有实现已验收。
