# 0004 工程底图与已校准的客户展示底图分开保存

Status: Accepted
Date: 2026-10-15

后续更新：历史整套方案、独立商品展示素材及楼层缓存已由 [ADR 0005](0005-project-delivery-and-reusable-visuals.md) 实现；下文有关旧出口历史限制与实时读取的描述保留为决策背景，以新决策为准。

## Context

工程 CAD 净底适合编辑与施工核对，客户已认可的彩平风格更适合方案展示。此前两个用途混在一起：部分 PDF 使用已烧录旧点位的静态彩平，实时导出则只读取黑白工程底图。商品和点位即使已更新，静态成品也不会变化；直接替换工程底图又会失去 CAD 坐标基准。

生成式彩平与 CAD 可能存在局部差异，仅按图片长宽比叠放不能证明位置准确。商品选型还可能保存在报价行的 `pointIds` 关系中，不能仅凭点位的 `productId` 判断是否已选商品。

本决策保留 ADR 0002 的工程坐标和 CAD 交换约定，细化 ADR 0003 的交付图形规则：工作台和 CAD 继续使用同源设备符号，客户 PNG/PDF 可以使用真实商品圆图；符号与商品图片都不是兼容性证明。

## Decision

### 两份底图，共用工程坐标

- 楼层 `floorplanDataUrl`、工程尺寸、CAD 绑定和点位 `x/y` 保持工程基准。工作台在这份底图上编辑。
- 可选 `floor.presentation` 保存无点位的风格净底：`name`、`imageDataUrl`、`imageWidth`、`imageHeight`、`sourceFingerprint`、`matrix`、`anchors`。禁止以已标点的方案成品作为净底。
- `sourceFingerprint` 为工程 `floorplanDataUrl` 完整字符串按 UTF-8 编码后的 SHA-256；它不是解码 PNG 字节的 SHA-256。导入与导出均核对它，工程图变化后旧校准不能继续使用。
- 矩阵按完整图片百分比坐标表达：`[a,b,c,d,e,f]`，`x' = a*x + c*y + e`、`y' = b*x + d*y + f`。只转换展示时的点位投影，不重绘、变形或覆盖工程图与风格图，不写回点位坐标。
- 锚点保留工程 `source` 和风格 `target` 百分比位置。要求至少 3 个非共线锚点、覆盖主体横纵跨度各至少 50%，检查矩阵比例、方向及图像范围；最大二维百分比残差超过 2% 拒绝绑定。残差可接受不代表生成图与施工几何完全一致。

### 三个导出入口共用渲染

- 当前楼层 PNG、报价 PDF、项目方案 PDF 都请求 `background: "presentation"`。有有效展示底图时使用展示底图；未绑定时使用工程净底。已绑定但指纹、尺寸或校准失效时停止导出，不能静默回退旧图或黑白图。
- 三个入口均使用 `buildPointMapProductVisuals`：按当前楼层已定位点位，优先采用已保存报价的 `pointIds` 精确商品映射，未被覆盖时使用点位 `productId`；明确的 `materials[].productId` 配套材料不替代主设备。一个点位对应多个不同主商品时报错。
- 商品图片优先使用报价行图片，其次使用该商品的产品库图片；不按图标、名称或类别猜具体 SKU。没有商品映射时使用分类圆形符号。有商品映射却缺图或图片读取失败时，三个入口均以 `strictProductImages` 停止导出。
- 商品照片等比例 contain 于圆内，保留分类色底的边缘、描边和轻阴影。只加载当前渲染楼层实际使用的商品图片。

### 保存边界明确

- 风格净底通过 `fmkj-point-map-presentations` v1 JSON 包导入当前草稿，再由工作台保存到数据库。包准备工具为 `scripts/create-point-map-presentation-bundle.mjs --plan --calibration --output`。
- `samePointMapQuoteSource` 忽略展示底图附件；只新增或更换展示底图不会触发报价预览重算，更不会替换已保存报价。点位版本可能递增，而商品报价保持原版本。
- 三个导出入口的商品关系都来自已保存报价。PNG 的位置和底图使用当前工作台草稿；两个 PDF 使用服务器已保存的点位方案。跨页面导出前必须先保存点位修改。
- 报价 PDF 有未保存的报价修改时先保存，成功后重新 GET 服务器报价，再读取已保存点位方案生成页面；失败停止打印。项目方案页读取已保存资料，后续保存完成后需刷新或重新打开该页。
- 查看旧点位版本时，PNG 目前仍读取当前项目最新已保存报价，不保证还原历史商品照片；本决策不将其描述为完整历史方案重现。

## Consequences

移动点位或更换已保存报价商品后可以复用风格净底，重新合成受影响楼层，无需再让图像模型制作整张图。保存、数据库重开和三个出口使用同一套展示底图及商品映射规则，同时保留工程净底和施工坐标。
