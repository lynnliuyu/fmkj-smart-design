# 0005 完整交付版本与可复用的商品展示素材

Status: Accepted
Date: 2026-10-15

## Context

客户持续调整点位、报价及商品照片，需要复用已认可的底图和素材，并能回看每次发出的整套方案。ADR 0004 已统一工程坐标与客户净底，但旧出口分别读取实时资料，无法保证旧图、旧报价及商品照片一起重现。商品照片修正也不应触发报价改价或丢失本地编辑。

## Decision

- `product_visual_assets` 按商品保存展示图、来源、裁切、大小、图片核验依据及独立修订号；乐观并发控制与审计使用原产品管理权限，不改 SKU、参数、价格或其核验状态。待核和系列图可用于出图，但不能声称为准确 SKU 图片。
- `point.display` 保存圆图与文字的展示偏移。安装 `x/y` 和 CAD 坐标不变，展示变化不触发采购来源重算。手工位置优先保留，其余点位自动避让；无法容纳则提示调整。
- `project_deliveries` 保存不可变完整交付版本，包含 plan、校准净底、场景、报价实际单价/小计/金额、商品图片字节和素材信息。创建以 repeatable-read 事务读取，以内容指纹去重；既有内容复用原版本。当前本地素材字节在创建时归档为 data URL，历史读取不依赖当前目录文件。
- 明确区分当前资料预览与固定 V 版本。工作台入口先保存本页点位，报价 PDF 先保存本页报价；方案页生成读取服务器已保存资料，不代替保存其他标签页的编辑。预览打印先生成固定版本；历史版直接使用其原资料。
- 报价明确 `pointIds` 覆盖点位产品的规则保留。生成检查实际来源、房间、数量和配套材料，不因展示附件修订号不同就重算报价。生成本身不调价、重新采购核验或写回点位产品。
- “更新商品图片”只更新当前草稿有效行的图片与素材快照。使用报价 ID/更新时间防止竞争，浏览器保留其他尚未保存编辑；旧交付不回写。
- PNG 与两种 PDF 共用渲染规则和楼层内容缓存。缓存只包含影响画面的来源，价格或场景说明变化不使楼层失效；受影响楼层重新合成。缓存失败不影响导出。
- 场景与点位、报价商品由已有 ID 关系联动，高亮不写进交付图。不自动将建议场景变成客户确认场景。

## Consequences

此决策替代 ADR 0004 的历史全套方案不可恢复限制，同时保留其工程坐标、校准和商品映射优先级。旧点位确认版本继续独立存在，不自动补造过去的报价。完整版本存储图片会增加数据库体积，设置单图、整包限制；远程展示图要求先归档，原来源 URL 仅供追溯。

客户可以从同一交付页下载 PNG、打印方案、查看版本差异，并在后续调整时复用净底和未变化楼层。实际步骤见 [导出工作流](../point-map-visual-presentation-workflow.md)。
