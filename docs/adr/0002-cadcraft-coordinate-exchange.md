# 0002 Cadcraft 使用稳定点位 ID 交换楼层坐标

Status: Accepted
Date: 2026-10-14

## Context

客户 PDF 开关图含尺寸、连线与注释，影响点位方案呈现。已安装的 Cadcraft 能从客户 DWG 提取分层矢量净底，并以原生图块编辑设备位置。工作台已有产品、控制灯组、场景、报价及确认版本，需要保留这些业务数据。

## Decision

- 工作台继续使用原图百分比坐标。CAD 底图增加可选绑定：独立图纸 ID、净底 DXF 的 SHA-256、固定的 CAD Y-up 窗口。图片比例必须与该窗口一致。更换图片会解除绑定，不能沿用旧窗口。
- 浏览器和本地 Node 24 桥接工具共同使用 `lib/point-map-cad-contract.ts` 的类型与运行时校验器。每次导出一个楼层的已定位点位，记录项目、底图、背景摘要、稳定点位 ID 和基线位置。
- Cadcraft 中的设备是带不可见标识属性的原生图块。图块 handle 可在保存时变化，不用于业务身份。源 CAD 不覆盖；输出为独立衍生 DXF。
- 回传先预览，显式应用时重新校验最新方案。只更新坐标，保留所有业务字段；移动点位和引用它的场景重新待复核。再次导入相同结果不改变状态或时间。
- 项目、楼层、底图绑定、背景摘要、点位集合或基线坐标冲突时拒绝整包。删除、复制或炸开图块不会变成设备的自动增删。工作台已有普通草稿导入仍保留同 ID 的人工编辑。

## Consequences

本地文件可完成双向调整，无需服务器执行 CAD 命令、上传客户图纸或为桌面进程开放网络端口。首版由本地桥接工具转换交换文件；工作台与 Cadcraft 不实时同步。客户不同版本图纸的配准属于待复核的设计输入，不能由坐标换算代替人工确认。
