# Triage 标签

工程类 skills 使用五个标准 triage 状态。本文件把这些标准状态映射到本仓库实际使用的 GitHub label。

| Skill 标准标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待提交者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分说明，可以交给 agent 独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或判断 |
| `wontfix` | `wontfix` | 不计划处理 |

当 skill 提到某个 triage 状态时，使用表格中对应的“本仓库标签”。
