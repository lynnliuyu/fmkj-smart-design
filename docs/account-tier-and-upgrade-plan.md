# 账号等级与付费升级计划

## 1. 账号体系目标

建立清晰的多等级账号体系，支持平台运营管理、企业团队协作、个人付费升级和免费用户转化。

账号体系分为：

- 超级管理员账号
- 企业版账号
- 个人版升级账号
- 个人版免费账号

## 2. 账号等级定义

### 2.1 超级管理员

超级管理员是平台最高权限账号，用于平台方内部运营和管理。

核心能力：

- 管理所有账号，包括企业账号、个人升级账号、个人免费账号
- 查看、创建、禁用、恢复、删除账号
- 修改账号套餐、到期时间、项目额度和功能权限
- 管理平台功能开关
- 查看平台数据统计
- 管理订单、付款记录、退款记录
- 管理企业账号下的主账号、子账号和团队结构
- 配置付费套餐、价格、权益和升级规则

### 2.2 企业版主账号

企业版主账号是企业客户的最高管理账号，拥有团队管理能力。

核心能力：

- 使用企业版全部业务功能
- 创建和管理团队
- 创建、邀请、禁用、移除子账号
- 设置子账号角色
- 管理子账号权限
- 查看团队项目、成员操作和使用情况
- 分配项目、点位图、数据资源等使用权限
- 管理企业资料、发票信息和付费订阅

### 2.3 企业版子账号

企业版子账号由企业版主账号创建或邀请，权限由主账号分配。

核心能力：

- 登录并使用企业分配的功能
- 访问被授权的项目
- 根据角色权限创建、编辑、查看或导出数据
- 使用点位图功能，前提是角色被授权
- 无法管理企业订阅和付款信息
- 无法越权管理其他成员

建议默认角色：

- 管理员：管理团队成员、项目、权限和企业内配置
- 编辑者：创建和编辑项目、使用点位图、上传和维护业务数据
- 查看者：查看项目和数据，不能编辑或删除
- 财务：查看订单、发票和订阅信息，不能操作项目数据

### 2.4 个人版升级账号

个人版升级账号面向个人付费用户，拥有完整个人使用能力，但不包含团队协作能力。

核心能力：

- 使用基础功能
- 创建多个项目
- 使用点位图功能
- 使用高级导出、数据保存、历史记录等付费功能
- 查看个人订单和订阅状态

限制：

- 无法创建团队
- 无法创建子账号
- 无法管理其他账号权限
- 无企业组织空间

### 2.5 个人版免费账号

个人版免费账号用于新用户体验和转化。

核心能力：

- 使用基础功能
- 创建 1 个项目
- 保存基础数据
- 体验核心流程

限制：

- 项目数量限制为 1 个
- 无法使用点位图
- 无法创建团队
- 无法创建子账号
- 无高级导出
- 无批量处理能力
- 无企业级权限管理

## 5. 升级路径

### 5.1 免费版升级到个人升级版

触发场景：

- 用户创建第 2 个项目
- 用户点击点位图功能
- 用户使用高级导出
- 用户达到免费版容量限制

升级提示：

- 当前免费版仅支持 1 个项目
- 点位图为升级版功能
- 升级后可创建多个项目并使用点位图

### 5.2 免费版升级到企业版

触发场景：

- 用户点击团队功能
- 用户尝试邀请成员
- 用户尝试创建子账号
- 用户需要多人协作

升级提示：

- 团队和子账号功能仅企业版支持
- 企业版支持成员管理、角色权限和企业协作

### 5.3 个人升级版升级到企业版

触发场景：

- 用户需要团队协作
- 用户需要创建子账号
- 用户需要角色权限管理
- 用户需要企业发票和统一付款

升级规则：

- 保留个人项目
- 可将个人项目迁移到企业空间
- 已支付个人版剩余时长可折算为企业版抵扣金额

超级管理员后台需要包含以下模块：

- 账号管理
- 企业管理
- 套餐管理
- 订单管理
- 权限管理
- 项目管理
- 平台功能开关
- 数据统计
- 操作日志

企业主账号后台需要包含以下模块：

- 团队成员
- 角色权限
- 企业项目
- 订阅与订单
- 发票信息
- 企业资料
- 使用统计

个人账号中心需要包含以下模块：

- 我的项目
- 当前套餐
- 升级付费
- 订单记录
- 个人资料

## 7. 关键产品规则

- 免费版最多只能创建 1 个项目。
- 免费版不能使用点位图。
- 个人升级版可以使用点位图，但不能创建团队和子账号。
- 企业版主账号可以创建团队和子账号。
- 企业版子账号的功能由角色权限决定。
- 超级管理员可以管理所有账号、套餐、平台功能和订单。
- 企业版账号到期后，进入宽限期，宽限期内可查看数据但限制新增和编辑。
- 免费版升级后，原有项目和数据保留。
- 企业主账号删除子账号时，子账号创建的数据应转交给企业主账号或指定管理员。

## 8. 验收标准

### 8.1 账号等级验收标准

- [ ] 超级管理员可以查看和管理平台内所有账号。
- [ ] 超级管理员可以修改账号套餐、到期时间、功能权限和账号状态。
- [ ] 超级管理员可以进入平台功能管理、套餐管理、订单管理和数据统计模块。
- [ ] 企业版主账号可以创建团队空间。
- [ ] 企业版主账号可以邀请、创建、禁用、移除企业子账号。
- [ ] 企业版主账号可以为子账号分配角色和权限。
- [ ] 企业版子账号只能访问被授权的企业项目。
- [ ] 企业版子账号只能使用角色允许的功能。
- [ ] 个人升级版账号可以创建多个项目。
- [ ] 个人升级版账号可以使用点位图。
- [ ] 个人升级版账号无法创建团队。
- [ ] 个人升级版账号无法创建子账号。
- [ ] 个人免费账号只能创建 1 个项目。
- [ ] 个人免费账号创建第 2 个项目时，系统阻止创建并展示升级入口。
- [ ] 个人免费账号无法使用点位图。
- [ ] 个人免费账号点击点位图入口时，系统展示升级提示。

### 8.2 功能限制验收标准

- [ ] 项目创建接口必须校验当前套餐的项目数量上限。
- [ ] 点位图入口和点位图相关接口必须校验当前套餐和角色权限。
- [ ] 团队功能入口必须校验是否为企业版能力。
- [ ] 子账号创建接口必须校验企业套餐、成员数量上限和角色权限。
- [ ] 高级导出功能必须校验套餐权益和角色权限。
- [ ] 企业订阅、订单、发票信息仅企业主账号、财务角色和超级管理员可查看。

### 8.3 到期和数据处理验收标准

- [ ] 企业版账号到期后进入宽限期。
- [ ] 宽限期内企业成员可以查看已有项目和数据。
- [ ] 宽限期内企业成员不能新增项目、编辑项目、邀请成员或使用点位图编辑能力。
- [ ] 宽限期结束仍未续费时，企业空间进入过期状态。
- [ ] 过期状态下数据保留，但付费功能被锁定。
- [ ] 免费版升级后，原有项目和数据必须保留。
- [ ] 个人升级版升级到企业版后，用户可以选择将个人项目迁移到企业空间。
- [ ] 企业主账号移除子账号时，系统要求选择数据接收人。
- [ ] 子账号被移除后，其创建的数据归属转移给企业主账号或指定管理员。

### 8.4 边界规则

- 个人升级版降级到免费版时，系统保留所有项目，但只允许编辑 1 个项目；超出免费额度的项目进入只读或归档状态。
- 免费版项目数量按 active 状态项目计算；archived 项目不计入项目数量上限，但归档项目恢复为 active 时必须重新检查额度。
- 个人免费账号已有 1 个 active 项目时，不能从 archived 恢复第 2 个 active 项目。
- 免费版不删除点位图数据，但当前套餐不包含点位图时，点位图只能被锁定或隐藏，不能编辑。
- 企业版过期后，企业空间数据保留；新增、编辑、邀请成员、角色调整和点位图编辑被锁定。
- 企业成员 v1 默认只能属于 1 个企业组织；多企业组织成员关系作为未来扩展。
- 企业主账号不能直接删除仍有未转移数据的子账号。
- 子账号移除后，该子账号不能再访问原企业项目和点位图。
- 套餐升级、续费和恢复订阅后，被锁定的项目、点位图和团队能力应恢复可用。

## 9. 数据模型建议

### 9.1 核心实体

| 实体 | 说明 | 关键字段 | 备注 |
| --- | --- | --- | --- |
| User / 用户 | 登录身份和基础资料 | id, email, phone, name, created_at | 不直接承载套餐和企业角色 |
| AccountProfile / 账号档案 | 用户账号类型和账号状态 | user_id, account_type, account_status | 区分超级管理员、企业主账号、企业成员、个人升级版、个人免费版 |
| Organization / 企业组织 | 企业空间主体 | id, name, owner_user_id, status, created_at | 企业项目、成员、订阅挂在企业组织下 |
| OrganizationMember / 企业成员 | 用户与企业的成员关系 | id, organization_id, user_id, role_id, member_status | v1 默认一个用户只加入一个企业 |
| Role / 角色 | 企业内角色定义 | id, organization_id, name, scope, is_system | 可包含系统默认角色和企业自定义角色 |
| Permission / 权限点 | 原子能力标识 | id, code, name, description | 使用 lowercase dotted code |
| RolePermission / 角色权限 | 角色与权限点关系 | role_id, permission_code | 用于企业子账号权限控制 |
| Plan / 套餐 | 商业套餐和功能额度 | id, plan_code, name, billing_cycle, limits | 套餐与账号类型分离 |
| Subscription / 订阅 | 用户或企业当前套餐状态 | id, subject_type, subject_id, plan_id, status, starts_at, ends_at | subject_type 为 user 或 organization |
| Project / 项目 | 用户或企业创建的业务项目 | id, owner_type, owner_id, status, created_by | owner_type 为 user 或 organization |

### 9.5 实体关系规则

- 一个用户 User 对应一个账号档案 AccountProfile。
- 一个企业组织 Organization 有一个 owner_user_id，指向企业主账号用户。
- 一个企业组织 Organization 可以有多个企业成员 OrganizationMember。
- 一个企业成员 OrganizationMember 在 v1 中只有一个角色 Role。
- 一个角色 Role 可以关联多个权限点 Permission。
- 一个个人项目属于一个用户 User。
- 一个企业项目属于一个企业组织 Organization。
- 一个个人版订阅属于一个用户 User。
- 一个企业版订阅属于一个企业组织 Organization。
- 一个企业成员 v1 默认只属于一个企业组织。

### 9.6 套餐限制字段

每个套餐需要配置以下限制：

- max_projects：项目数量上限
- max_members：成员数量上限
- can_use_point_map：是否可使用点位图
- can_create_team：是否可创建团队
- can_create_sub_accounts：是否可创建子账号
- can_use_advanced_export：是否可使用高级导出
- storage_limit：存储容量上限
- support_level：客服等级

## 10. 权限判断流程

### 10.1 核心权限点

关键能力拆为权限点：

```text
account.manage_all
platform.manage_features
enterprise.manage_members
enterprise.manage_roles
enterprise.manage_billing
project.create
project.edit
project.view
project.delete
point_map.use
export.advanced
order.view
```

### 10.2 服务端判断顺序

服务端权限判断为准，前端判断只用于隐藏入口、展示提示和减少无效操作。所有涉及账号、项目、点位图、团队、导出、订单和平台管理的接口都必须做服务端权限判断。

判断顺序：

1. 校验用户是否已登录。
2. 检查账号状态是否为 active。
3. 解析账号类型。
4. 解析当前订阅和套餐限制。
5. 如果资源属于企业，解析企业组织、企业成员和角色。
6. 检查资源归属或企业成员关系。
7. 检查原子权限点。
8. 返回允许或拒绝，并提供机器可读拒绝原因。

### 10.3 拒绝原因

| 拒绝原因 | 触发场景 | 用户动作 | 是否展示升级入口 |
| --- | --- | --- | --- |
| NOT_AUTHENTICATED | 用户未登录 | 引导登录 | 否 |
| ACCOUNT_DISABLED | 账号被禁用 | 联系平台管理员或客服 | 否 |
| PLAN_REQUIRED | 当前套餐不包含该能力 | 选择可用套餐 | 是 |
| PROJECT_LIMIT_REACHED | 项目数量达到套餐上限 | 升级套餐或归档项目 | 是 |
| POINT_MAP_NOT_INCLUDED | 当前套餐不包含点位图 | 升级到个人升级版或企业版 | 是 |
| TEAM_FEATURE_REQUIRED | 当前套餐不包含团队功能 | 升级到企业版 | 是 |
| ROLE_PERMISSION_DENIED | 企业成员角色无权限 | 联系企业主账号或管理员 | 否 |
| RESOURCE_NOT_FOUND_OR_NOT_OWNED | 资源不存在或不属于当前用户/企业 | 返回无权限或不存在提示 | 否 |
| SUBSCRIPTION_EXPIRED | 订阅已过期且超出宽限期 | 续费或升级 | 是 |
| PLATFORM_ADMIN_REQUIRED | 需要超级管理员权限 | 切换到超级管理员账号 | 否 |

### 10.4 判断示例

- 个人免费账号创建第 2 个项目：检查 `max_projects`，返回 `PROJECT_LIMIT_REACHED`，展示个人升级版和企业版升级入口。
- 个人免费账号打开点位图：检查 `can_use_point_map`，返回 `POINT_MAP_NOT_INCLUDED`，展示升级入口。
- 个人升级版账号邀请团队成员：检查 `can_create_team` 和 `can_create_sub_accounts`，返回 `TEAM_FEATURE_REQUIRED`，展示企业版升级入口。
- 企业子账号访问未授权项目：检查企业成员关系、项目归属和角色权限，返回 `RESOURCE_NOT_FOUND_OR_NOT_OWNED` 或 `ROLE_PERMISSION_DENIED`。
- 企业主账号管理订阅和发票：检查企业 owner_user_id 和 `enterprise.manage_billing`，通过后允许访问。
- 超级管理员修改用户套餐：检查账号类型为 `SUPER_ADMIN` 且具备 `account.manage_all`，通过后允许修改。

## 11. 订阅与付费状态

### 11.1 订阅状态

| 状态 | 说明 | 新建项目 | 点位图 | 团队成员管理 | 升级/续费提示 |
| --- | --- | --- | --- | --- | --- |
| FREE | 免费状态 | 仅 1 个项目 | 不可用 | 不可用 | 触达付费能力时展示 |
| ACTIVE | 订阅有效 | 按套餐额度 | 按套餐权益 | 企业版可用 | 可展示续费或套餐管理 |
| GRACE_PERIOD | 到期宽限期 | 不可新增 | 只读或锁定编辑 | 不可新增或调整成员 | 展示续费 |
| PAST_DUE | 扣款失败或待支付 | 不可新增 | 只读或锁定编辑 | 不可新增或调整成员 | 展示支付重试 |
| EXPIRED | 已过期 | 不可新增 | 不可用 | 不可用 | 展示续费 |
| CANCELED | 已取消续订 | 到期前按 ACTIVE，到期后按 EXPIRED | 到期前按套餐权益 | 到期前按套餐权益 | 展示恢复订阅 |

### 11.2 免费版升级到个人升级版流程

1. 用户触发第 2 个项目、点位图、高级导出或容量限制。
2. 系统展示升级提示，说明免费版限制和个人升级版权益。
3. 用户选择个人升级版月付或年付。
4. 用户完成支付。
5. 系统将订阅状态更新为 ACTIVE，并绑定个人升级版套餐。
6. 系统保留原有项目和数据。
7. 支付失败时，账号保持免费版，原操作继续被拒绝，并提示重新支付。

### 11.3 免费版升级到企业版流程

1. 用户触发团队、邀请成员、创建子账号或多人协作能力。
2. 系统展示企业版升级提示。
3. 用户填写企业资料并选择企业版套餐。
4. 用户完成支付。
5. 系统创建 Organization，并将当前用户设置为 ENTERPRISE_OWNER。
6. 系统创建企业订阅，状态为 ACTIVE。
7. 用户可选择保留个人项目或迁移项目到企业空间。
8. 支付失败时，不创建企业空间或保持企业空间为未激活状态。

### 11.4 个人升级版升级到企业版流程

1. 用户触发团队、子账号、角色权限、企业发票或统一付款能力。
2. 系统展示企业版升级入口。
3. 用户选择企业版套餐并填写企业资料。
4. 系统计算个人升级版剩余时长可抵扣金额。
5. 剩余时长抵扣规则需财务最终确认；未确认前按“人工或后台配置抵扣”处理。
6. 用户完成支付。
7. 系统创建企业组织和企业订阅。
8. 用户选择将个人项目迁移到企业空间，或继续保留在个人空间。

### 11.5 降级规则和取消规则

- 个人升级版取消续订后，到期前继续保持 ACTIVE 权益。
- 个人升级版到期后降级为免费版，保留所有项目，但只允许 1 个 active 项目可编辑。
- 超出免费额度的项目进入只读或归档状态。
- 当前套餐不包含点位图时，点位图数据保留，但点位图编辑和访问入口被锁定。
- 企业版取消续订后，到期前继续保持企业版权益。
- 企业版到期后进入 GRACE_PERIOD，宽限期内只读访问已有数据。
- 企业版宽限期结束后进入 EXPIRED，企业协作、点位图编辑、成员管理和新增项目被锁定。
- 企业成员数量超过当前套餐额度时，不能新增成员；已有成员是否保留访问按企业当前订阅状态和后台配置决定。

## 12. 建议开发优先级

### 12.1 第一阶段：个人账号和平台基础权限

交付目标：

- 建立账号等级字段和基础套餐字段。
- 实现个人免费版限制。
- 实现个人升级版入口。
- 实现超级管理员账号管理。

包含能力：

- 账号类型枚举
- 套餐类型枚举
- 免费版项目数量限制
- 点位图权限限制
- 个人升级版付费入口
- 超级管理员账号管理

完成标准：

- 免费用户不能创建第 2 个项目。
- 免费用户不能使用点位图。
- 个人升级版可以使用点位图和多项目。
- 超级管理员可以查看和管理所有账号。

### 12.2 第二阶段：企业账号和团队协作

交付目标：

- 支持企业主账号、企业组织、子账号和基础角色权限。
- 支持企业版付费计划。

包含能力：

- 企业主账号
- 企业组织
- 子账号邀请和禁用
- 基础角色权限
- 企业成员数量限制
- 企业版订阅

完成标准：

- 企业主账号可以创建和管理子账号。
- 子账号只能访问授权项目。
- 企业版可以使用点位图和多项目。
- 企业版可以管理团队成员和角色权限。

### 12.3 第三阶段：高级企业能力和运营后台

交付目标：

- 支持更细粒度权限、企业统计、订单发票和操作审计。

包含能力：

- 细粒度权限
- 企业使用统计
- 发票和订单管理
- 操作日志
- 企业高级版和定制报价

完成标准：

- 企业主账号可以查看团队使用统计。
- 财务角色可以查看订单和发票。
- 平台可以查看关键操作日志。
- 企业高级版可以通过后台配置更高额度和定制权益。
