# 开关图分析、点位微调与场景出图

## 实际操作

报价补充规则（2026-10-15）：默认型号允许直接进入客户报价，但保留“未核验 · 默认型号”标识，不代替下面的严格采购核验。项目内统一默认型号只影响本项目未指定商品的点位；预留点仍不计入。详见 [ADR 0006](adr/0006-project-quotation-defaults-and-linked-deletion.md)。

1. 先整理客户原图：如果收到 DWG / DXF，先用 CADCraft 导出 **Model、全部布局总览和可识别图框的逐页 PDF / PNG 对照包**，打开目录并排查看，确认本次采用的楼层、方案与开关图，再提取净底；不能直接挑一张净图开始布点。重复图名、重复页码和历史方案都保留。没有图框的区域从总览核对，空视口 / 缺图明确标记，不能当作已完整识别。工具入口见[DWG 原图逐页对照](cadcraft-point-map-bridge.md#dwg-原图逐页对照先于净底)。已有 PDF / 图片时先核对页数和版本。选定清晰开关图后，助手按完整图片范围记录建议位置、楼层、编号、控制灯组及待复核事项，交付点位草稿文件。
2. 在客户项目中打开「方案报价 → 打开点位规划」。展开「高级工具 → 导入助手点位草稿」，选择文件，点击「校验并预览」，核对楼层、点位与场景数量，再点击「确认预摆点位」。
3. 如果草稿已包含底图，点位直接显示；否则切换每个楼层并上传对应的完整图片。按图纸原始比例上传，裁剪过的图片需要重新定位。
4. 使用放大、平移、拖动或方向键微调。画布上方可搜索点位、按房间筛选，并显示当前楼层命中数量；右上角「全屏编辑」让画布占满窗口。复核用的「房间进度」「点位清单」「场景与联动」「待定位」都在顶部按需弹窗打开，不占画布。点位详情可编辑编号、房间、控制灯组、控制方式与复核备注；房间支持自定义。在「设备要求与选型」中确定类型及现场要求，暂不清楚的参数留空。一个实体面板对应一件产品，按键、继电器路数与控制灯组分别记录。
5. 审核场景的触发方式、动作和关联点位，入口是顶部「场景与联动」（弹窗内逐个确认）。场景建议不会自动变成已确认状态。实际图纸条件不明确时保留「需复核」。
6. 点击「保存草稿」保存到项目。定位、点位与场景的复核状态随草稿保存；客户出口用固定交付版本，不做单独的「确认版本」快照。
7. 在高级工具中点击「导出草稿 JSON」把微调后的数据交回助手继续评审或出图；也可以直接点击「草稿检查 PNG」，仅输出当前楼层底图与商品 / 分类圆图，供当前草稿检查；控制关系、备注和场景保留在结构化数据与客户方案中。正式客户 PNG 与 PDF 从「客户交付」使用固定 V 版本导出。工作台和 Cadcraft 使用同源矢量图标，最终 PNG 以工作台为准；橙色短条表示需复核。未定位的点位不在画布上画假位置，只从顶部「待定位」清单逐个定位。
8. 保存点位草稿后，系统自动按已保存 revision 更新本机报价预览；进入「报价单」核对并保存，才写入数据库报价。未指定产品的非预留点可按本项目默认型号形成未核验客户报价；无可用默认型号时保持待选。明确关联产品的严格采购路径仍要求正式选用、已核验兼容型号、设计确认与完整配套用料，阻塞时保留原报价。重复预览替换本项目点位来源条目，保留手动行及人工调整的单价、成本和折扣。不要将本机预览或未核验报价当成已完成采购核验。

9. 在报价页删除点位来源行或区域，保存时同时删除其关联安装点和场景引用，受影响场景重新待复核；手动行不删点位。保存前仍可取消编辑，过期 revision 会拒绝保存。历史确认版与完整交付版保持原样。

## 布局、灯光、开关图对照

在“图纸对照”切换三图，缩放和平移保持一致；安装点始终记录在布局净底上。已有配准包时点击“导入已配准图纸包”，普通图片在对应图签点击“添加并配准”，依次在布局与对照图上选三组同一建筑角点，横纵各跨过图幅一半，不能共线。核对墙体后完成配准并保存草稿。切图不会增加设备件数或改报价。

对照图缺失或来源过期时不可在其上布点。换布局后需重新配准；显式整理留白会同步换算有效配准。CAD 包的无需 AI 准备入口见 [同坐标对照图](cadcraft-point-map-bridge.md#同坐标灯光与开关对照图)。这些图只供设计核对，客户交付继续使用已绑定的展示底图 / 工程净底。

## 修改与恢复

- 相同 ID 的草稿重复导入会保留已微调的点位，不重复添加。需要修改现有点位时直接编辑工作台，或先把最终 JSON 交回助手比较。
- 换底图、修改已确认点位或修改场景内容会重新打开相关复核状态。相同底图重新上传不会撤销确认。
- 云端有更新时（通常是自己在报价单删行联动改了点位、开了另一个标签页，或页面放了很久），过期保存会提示冲突并保留本机草稿。两条出路：**以本机为准保存**会先读回云端当前版本、自动把被替换的一版存为本机备份，再以它为基准覆盖；**加载云端草稿**则放弃本机修改。想留档先「导出本机 JSON」或「导出本机备份」。
- 本机图片与文字分开保存在 IndexedDB，相同图片只存一份，旧缓存自动迁移成功后才清除。浏览器仍可能清理站点数据，本机副本不代替数据库和 JSON 备份；存储失败时页面明确提醒。保持页面打开并保存到云端或导出 JSON，避免只依赖当前页面的临时数据。
- 草稿里的复核状态表示用户已核对的设计方案，不代替设备参数和现场施工条件复核。
- 关联型号的关键资料更新后，原选型快照继续保留并提示重新核验。核对变化后点击「重新选择当前型号」并保存；普通重复保存不会把旧选型静默更新为新规格。

## 产品准备与点位选型

产品后台先区分「系列」「具体规格」与待整理资料，再按设备类型填写参数和依据，分别审核参数与价格。旧产品迁移后保持待核，不会因为名称像某个设备就进入已核候选。多个键数或接线版本混写的记录可保留为系列，具体供货 SKU 按已证实的资料补录；整理操作见[产品库与点位映射](product-point-mapping-plan.md)。

在点位中选择「设备类型」，填写带 `*` 的关键要求，再从「关联具体型号」选择兼容 SKU。开关的按键数、继电器路数和接线方式均需明确；四寸屏的尺寸、供电和负载也要分别核对。无兼容产品时，页面列出待补资料，仍可保存和确认布局。原有不兼容关联会提示原因，需人工重新选择。

「选用状态」控制采购范围：待评估用于候选设计，预留用于保留位置，正式选用表示本次采购意图。正式选用仍需定位、设计确认、具体规格和价格核验，才能通过采购预览。修改类型、关键要求或型号会重新打开设计复核；移动位置沿用原有定位复核规则。

窗帘继续以轨道＋电机一个图标表示。主产品选择电机或明确范围的套装，在「配套用料」添加轨道与必配件，填写实际型号、单位和实测长度；支持 3.6 米等小数。未知长度留空，套装已含部件据实际范围勾选，不另计费用。只有电机或必配材料待定的正式选用点会阻断报价同步。报价中的米、配件和服务保持原计量，不能按四舍五入数量生成实体点位。

## 助手交付格式

坐标为完整底图的百分比，左上角为 `(0, 0)`、右下角为 `(100, 100)`。楼层 ID、点位 ID 与场景 ID 保持稳定；场景引用点位 ID。

```json
{
  "format": "fmkj-point-map-draft",
  "version": 2,
  "coordinateSystem": "image-percent",
  "floors": [{
    "id": "floor-1", "name": "一层",
    "floorplanName": "switch-floor-1.png", "floorplanDataUrl": "",
    "imageWidth": 800, "imageHeight": 400
  }],
  "points": [{
    "id": "floor-1-k01", "floorId": "floor-1", "code": "F1-K01",
    "name": "入口面板建议", "room": "玄关", "iconId": "switch-1",
    "x": 15, "y": 40, "placed": true, "status": "changed",
    "productId": "", "note": "",
    "deviceTypeId": "wall-switch", "requirements": {},
    "usage": "proposed", "materials": [],
    "controlTargets": [], "controlType": "",
    "confidence": "medium", "source": "analysis",
    "reviewReason": "符号作为占位，实际面板数量、键数与控制对象需复核。"
  }],
  "scenes": [{
    "id": "scene-home", "name": "回家建议",
    "trigger": "入口面板场景键（待确认）",
    "description": "建议开启入口照明，具体灯组待确认。",
    "pointIds": ["floor-1-k01"], "status": "proposed"
  }]
}
```

图片可以作为 PNG/JPEG/WebP data URL 包含在文件中，或随后由用户为相应楼层上传。文件校验失败时整个导入被拒绝，现有方案保持原样。原始客户图纸与实际分析输出放在本地 `.local/`，测试与仓库文档使用合成数据。

示例中的单开图标只是占位，`requirements: {}` 不表示单键或零火。当前助手草稿为 v2，继续接受旧 v1；工作台方案为 schemaVersion 3，继续读取旧单图与 v2 方案，图例固定为 symbolVersion 1。设备要求、选用状态、用料及选型快照经过保存、JSON 往返与 CAD 位置回传保留。客户端提交的选型快照由服务端核对，不能作为厂商参数已核实的凭据。

部署或接入新环境前，通过 `scripts/run-migration.mjs` 执行受账本管理的完整迁移，再同步设备类型字典；具体步骤见[产品整理操作](product-point-mapping-plan.md#迁移与产品整理操作)。迁移增加项目方案、产品选型和报价快照字段，既有方案及历史报价保留。

## Cadcraft 协作

已配准的净底草稿会携带 CAD 图纸身份和固定坐标窗口。导入空白项目后，展开「高级工具 → Cadcraft 协作」并导出当前楼层交换文件，使用[本地桥接工具](cadcraft-point-map-bridge.md)写入独立 DXF。在 Cadcraft 微调、保存后生成回传文件，回到同一项目、同一楼层读取，核对预览后应用。

回传只改位置，移动点位与关联场景需要重新复核；产品、房间、控制灯组与场景内容保留。导出后又在工作台移动的点位会提示冲突。替换底图将解除旧 CAD 绑定。普通草稿导入仍会跳过同 ID 点位，所以净底样板应导入空白项目，不能用它直接覆盖已微调的旧 PDF 方案。

这一步采用本地文件往返。客户 DWG/PDF、净底和点位样板保存在忽略的本地目录，不进入代码仓库。

## 综合设备布局

摄像头、AP、窗帘及弱电核心设备可以与开关点位一起规划。无线 AC 控制器与暖通空调使用独立类型。窗帘可按用户要求以轨道＋电机组合标一个安装点，长度、供电侧及成套范围待选型后另核；布局数量不等于采购或轨道米数。

增补草稿保留相同净底楼层身份，只带新增点位 ID；导入已有方案不会覆盖旧点微调。摄像头朝向、AP 覆盖意图和设备安装要求目前记录在备注，图标是类别符号，不能替代视场或射频验证。不确定的窗位和设备柜保留待定位，不自动确认或进入报价。

## 更换点位图标

在布点模式点击图上的设备即可打开编辑弹窗，选择同类 SVG 更换图标。开关与控制面板提供单开、双开、三开、四开、场景、调光、四寸屏和大屏中控；其他设备按类别提供选择。四寸屏沿用原 `panel-small` ID，旧“小屏中控”关键词仍可识别。跨类别选项收在折叠区。

更换单/双/三/四键或四寸屏会更新设备意图，保留点位 ID、位置、编号、房间、备注和控制灯组，解除原关联并重新核验型号。图标纯显示样式更新可以保留产品关联，兼容性仍由类型和要求决定。仅自动生成名称随类型更新，自定义名称保留；已确认点位与关联场景重新进入复核。选择当前图标不作修改。普通点按不提交坐标，实际拖动才更新位置。

编辑弹窗底部可直接“保存到数据库”，成功后显示保存编号；“完成编辑”仅关闭弹窗。保存失败、冲突和只读状态仍有明确反馈。

## 底图与图标尺寸约定

报价同步失败后，可在问题解决后再次“保存草稿”重试，点位内容没改也会重新生成报价预览；进入报价页核对并保存，才写数据库报价。默认窗帘电机可先作为未核验报价；未知轨道 / 配件明确显示“配套未计入本次报价，待核对后补报”，不假设米数。明确型号失效、单位或套装范围冲突仍需先纠正。正式采购校验不放宽。

所有客户工程净底导出统一长边 3000 px，短边按原图比例计算，禁止拉伸成固定宽高。工作台整体适配底图，设备符号保持 32 屏幕像素和 44 像素点击范围。数字角标代表相邻安装点的临时显示分组：点开逐个选择，或“放大查看这一组”；“局部布点”定位到选中点，“查看全图”返回整体。选中点独立显示并可拖动，完全同坐标的多个点仍可逐个选择，不合并设备或数量。编号只在选中、悬停或键盘聚焦时显示，减少文字遮挡。

编辑缩放与客户出图分别固定用途。PNG 与两类 PDF 共用渲染器，底图绘图区长边 3000 px（成品另含必要留白 / 说明），工程符号按固定输出像素排版；客户商品圆图沿用已接受的排版与引线。编辑时的分组、缩放和选中状态不写入客户交付。详见 [ADR 0008](adr/0008-consistent-editor-and-output-scales.md)。

净底先裁外围空纸，按建筑有效范围横纵各留约 3% 安全边距，再统一长边 3000px；房屋内部白色空间保留。布局、灯光、开关图配准后共用同一裁切范围，原图对照版保留图框。CAD 准备脚本默认执行，清单保存原窗口、裁切范围和新绑定；相关图用 `--crop-frame` 复用，坐标窗口不同的图先配准。

已有项目打开“高级工具 → 整理底图留白”。程序同步图片、点位百分比、CAD 窗口与风格校准，实际安装位置不动；商品展示偏移随对应坐标系换算，点位确认状态和场景引用保留。原稿可从“导出本机备份”下载；若提示备份仅在当前页面有效，关闭前先下载。处理后点击“保存草稿”才写数据库。外围有点位或锚点时会拒绝裁切，不能手工换小图后保留旧坐标。独立风格图片不裁切，保留原校准视觉；旧固定版本和历史交付不回写。
