## 用户要求

调整第一步：收到 DWG 时，先通过 CAD 软件导出里面的图纸，方便对照。用户进一步明确：本机或网页都可以，前提是不需要 AI 参与即可导出。采用本机 CADCraft 文件流程和 macOS 双击入口；不把网页图片上传宣称为已经接入本机 DWG 转换服务。

## 实现范围

- `pnpm run cad:review` 读取原图的只读副本，用 CADCraft 原生范围识别 Model / 布局图框；导出各空间总览和独立图框 PDF，再经 Poppler 生成 PNG。
- `scripts/export-cad-review.command` 是不依赖 AI 会话的 macOS 双击入口，自动定位 Node / CADCraft CLI / Poppler，选择文件，输出到用户文档目录并打开结果；命令行和双击共用同一导出 module。
- 生成可搜索、双栏对照的本地 HTML 和原图摘要 / 来源清单。重复图名、重复编号不合并，未识别图框仍从总览补核，空视口明确标记。没有完成清单就不视为成功。
- 更新工作台底图提示、CONTEXT、AI_RUNBOOK 和两个设计工作流；第一步由“直接交清晰开关图”改为“原图全览和逐页对照 → 用户选定方案 → 提取净底 → 预摆点位”。不改报价、正式交付版本或历史客户数据。

## 实际工具限制

整张模型图包含大量重复图元，直接展开 SVG 曾超时并产生过大中间文件；已清理该失败中间文件，改为 CADCraft 原生 PDF → Poppler PNG。总览保留全部模型图形，逐页只裁取识别图框范围。原图不删除文字、尺寸、电气或图例，不隐去原始颜色。

Model 识别常见纸张比例、图框层图块；布局识别包围视口的图框。特殊图框、无框内容需看总览核对；不能把识别页数写成原文件的完整页数。导出不选择最终方案，不自动进入净底或布点。

实图导出包：`.local/cad-review/示例项目-原图对照-20261015/`；验收摘要：`.local/cad-review/acceptance/results.json`。原生 PDF 保留复杂填充，合并文件约 301 MB；不通过删除填充或文字来缩小。大图转换设定请求 / 栅格化时限和文件上限，超限显示失败，不输出伪成功清单。测试不写主数据库，不覆盖现有客户图纸。

## 可读配色修复（2026-10-15）

用户反馈原色导出发亮、看不清。实际样张白底存在 40,610 个亮黄像素；PDF 原生内容包含 `1 1 0 RG` 黄线，属于输出配色问题。默认改为白底深色阅读配色：绘图描边用黑色，彩色文字轮廓和填充转深灰，保留纯白遮罩及既有灰度层次；不删文字、尺寸、几何、裁剪或线宽。原色 PDF / PNG 独立保存并提供切换。

真实样张修复后亮黄像素为 0，白底仍为白色；除颜色操作外，几何和文字绘图指令逐字节一致。修复路径加入导出 module，双击入口以后默认使用清晰配色；覆盖原色保存、配色处理在栅格化之前执行的回归通过。对照页默认打开单页而非整张模型总览，支持独立放大、缩小、适应窗口。

本次配色修复最终验收：71 张 PNG 均为灰度且尺寸与原色一致；71 页阅读版合并 PDF 与逐页阅读版内容流一致；原色文件、原色合并 PDF 和原始 DWG 保留。822 项全量测试、类型检查及改动文件 Lint 通过。桌面入口以黄色线条的合成 DXF 独立执行，默认完成清晰配色、原色副本和合并输出；验收记录见 `.local/cad-review/acceptance/palette-results.json`。

## 视口修复（2026-10-15）

用户指出灯具定位图 / 开关布置图空白。直接读取原 DWG 的 VIEWPORT 目标坐标后，两页模型查询从 0 恢复到约 1,900 个实体；灯具页与开关页的冻结图层也不同。修复使用本机固定版本 LibreDWG WASM 解码原始视口，在每次重开 CAD 私有副本后恢复目标偏移和冻结图层，再导出、转清晰配色。该流程不需要 AI、不修改原 DWG。

不支持的旋转、三维、透视或特殊裁剪视口明确报错；不能输出空白并推断为失效历史图。原图参数缺失或图层无法解析时同样停止。所有受影响布局和总览重新导出，旧 PDF 文件存在、页数或内容流一致不足以证明图纸完整。灯具定位图和开关布置图必须实际看图验收。
