# Plan 024：固定所有客户的布点可读性规则

Status: DONE
Date: 2026-10-15

用户否决随底图缩小后不可读的开关图标，并明确要求之后所有客户统一流程。正式规则见 ADR 0008。

- 重现：旧算法在 390 / 640 px 窗口把 28 逻辑像素图标缩到约 6.8 / 11.5 屏幕像素；新增回归先失败（实际 3.9 px / 预期 32 px），修复后通过。旧几何比例测试不能证明图标可读。
- 屏幕图标固定 32 px，交互范围 44 px；相邻点位按当前屏幕范围临时分组，数字角标与中性叠层图案避免误示设备身份。组内可逐个编辑、放大查看，选中点可独立拖动。
- 局部布点 / 清单定位移动相机，不移动实际点；全图恢复整体。标号仅在选中、悬停或聚焦时显示，保持原键盘微调、拖动阈值及设备图形。
- 源底图长边 3000、输出工程符号 56 px 和共享客户排版保持固定；编辑视口不进入点位业务数据或交付。没有修改主库、真实客户草稿、报价或历史 V 版本。

验证：全量 79 文件 / 835 项通过，类型及本次改动 Lint 通过。隔离 Vite 页面直接挂载真实 PointMapWorkbench（本地样张 31 个已定位点，项目 ID 为 synthetic visual-review），GET 来自专用只读夹具，所有写 API 返回 405。真实浏览器验证组内选择、编辑弹窗、放大组、返回全图、44/32 像素尺寸、方向键和拖动；拖动目标 x 从 78.7% 到约 81.7%，图标仍 32 px；定位后选中点距画布中心不足 0.01 px。窄 / 宽窗口无整页横向溢出。

回归覆盖显示分组随缩放拆分、整组跨度上限（避免整屋串成一组）、输入与顺序稳定、完全重合点的逐个取出、相机定位与不改安装坐标。主应用生产构建未在本轮重跑；上轮受 Google Fonts 下载连接失败阻断。隔离页面用于真实组件交互验收，不作为已部署或已保存客户项目的证据。
