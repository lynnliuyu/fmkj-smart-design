用户选择优化建议 2 与 4，固定规则见 ADR 0009。

## 实现

- point-map-local-store module 收拢图片去重、原字符串恢复、旧缓存迁移、原子提交、顺序写入与失败恢复。工作台、备份和报价加点共用入口，不把内存状态当作已保存。
- 楼层 references 增加灯光 / 开关图，配准校验复用 presentation module；reference module 负责三点拟合、逆变换、图纸包校验与来源过期检测。实际画布和安装点仍使用工程坐标。
- 普通图片可“添加并配准”，CAD 图纸包可直接导入。完整 JSON 往返和明确留白裁切保留 / 转换对照图，客户导出沿用已有来源。
- prepare-cad-reference-drawings.mjs 读取已核对的逐页清单，按原冻结图层和当前工程 WCS 窗口导出。SVG 超过 40MB 改走原生 PDF 及明确打印框裁切，不调用 AI，不改原图，不逐张独立紧裁。

## 验收

- 自动测试 83 文件 / 853 项通过；新增存储、配准、裁切重基准及原图窗口测试；报价异步调用兼容。类型检查和本次改动 ESLint 通过。

- 三图保持 125% 缩放及点位百分比 / 样式；图纸包导入与普通 PNG 三组建筑角点配准均通过实际页面验收。
