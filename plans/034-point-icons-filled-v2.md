# 计划 034：点位图标回到「实心」画风并生成 v2

Status: PROPOSED
Created: 2026-10-21
Depends on: 计划 019、ADR 0003

## 用户决定

- 用户明确优先使用 2026-06 那套**实心彩色**图标（`public/assets/point-icons/color/*.png`，2026-10-18 已删），并要求在旧图基础上优化后**重新生成**一套。
- 现存 v1 是细线描边风格，用户认为"图标都被换掉了"——这是 2026-10-14 那轮 ADR 0003 的设计结果，不是误删。

## 现状与约束（必须先承认）

1. 共享几何 `lib/point-device-symbols.mjs` 只有 `pline` / `rectang` 两种**描边**图元，SVG 渲染器固定 `fill="none"`。
2. Cadcraft 原生图块由 `scripts/cadcraft/bridge.mjs` 直接执行同一批图元命令（客户端只提供 pline / rectang / layer / attdef / block 等），**没有可用的填充或填充图案命令**。ADR 0003 之所以选择线描边，就是为了让工作台与 CAD 图块外观一致。
3. `lib/point-icons.ts` 里 `iconBasePath` 指向 `v1`，注释写明"已发布的 v1 图纸保留这些不可变资源"——所以新风格必须走 **v2 目录**，不能覆盖 v1。

## 决定（本计划要执行的方向）

- **屏幕风格走 v2「实心 + 白色镂空」**：工作台调色板、平面点位标记、图例、导出 PNG/PDF 全部读 v2。
- **CAD 原生图块保持线稿**：继续用同一份 `pline`/`rectang` 几何，客户端限制所致，视觉上与 v2 不同。
- 这属于对 ADR 0003「两边外观一致」的部分偏离，建议补一条 ADR 0011 记录：**几何仍然一份，差异只在渲染介质**；客户交付以工作台出图为准这一条不变。

## 设计语言（原型已确认方向）

原型对照见 `tmp/icon-compare/proto.png`（旧 PNG / v1 / 方案 A 粗描边 / 方案 B 实心）。

| 维度 | 规则 |
| --- | --- |
| 画布 | 48×48，安全边距 4 |
| 底板 | 面板类设备（开关、插座、面板、网关、AP、门锁、控制屏等）用 40×40、圆角 9 的实心底板 |
| 主体 | 灯具、窗帘、摄像头、传感器、门铃等"器物类"用实心剪影，不加底板 |
| 镂空 | 底板上的图形用白色（`#fff`）镂空线，线宽 2.5–3；剪影内部细节用白色或同色深浅 |
| 配色 | 沿用现有 `colors` 表，保证与 v1 同一设备同一色系 |
| 小尺寸 | 16 / 24 / 32px 三档检查可辨识度，24px 为平面标记的基准 |

## 实施步骤

1. **共享几何扩展**：在 `lib/point-device-symbols.mjs` 增加仅用于 SVG 的填充图元（例如 `["fill", { vertices, color }]`）与 `plate` 快捷构造；`symbolFor()` 返回的命令**保持不变**（CAD 只读 `commands`）。
2. **SVG 渲染器**：`renderPointDeviceSvg()` 支持填充图元（`fill` 属性，保留描边图元在上层），输出仍为 `viewBox="-1.4 -1.4 2.8 2.8"` 的等尺寸 SVG。
3. **生成脚本**：`scripts/generate-point-icons.mjs` 增加目标版本参数，生成 `public/assets/point-icons/v2/*.svg`（44 个）；`pnpm icons:build` 默认写 v2，v1 目录不再写入。
4. **切换引用**：`lib/point-icons.ts` 的 `iconBasePath` 改 v2；保留 v1 文件与注释（已发布图纸/历史交付引用不变）。
5. **测试**：更新 `tests/point-device-icons.test.ts` 的漂移检查为 v2，并新增一条断言 v1 文件仍存在且未被改写；补一条"每个 id 的 SVG 同时含填充与描边"的守卫。
6. **分批实施**：
   - 批次 1（12 个高频）：单/双/三/四开开关、场景面板、插座、USB 插座、窗帘电机、摄像头、网关、四寸屏、全屋 WiFi。
   - 批次 2（其余 32 个）：灯具、传感器、门锁门磁、NVR、暖通、配套用料等。
   每批都必须在工作台 24/32px、平面标记、导出 PNG、产品库设备图标 chip 四处看过。

## 验收

- 工作台设备调色板与点位标记为实心风格，24px 下可区分单/双/三开与四寸屏。
- 导出 PNG/PDF 的图例与点位与屏幕一致（同一批 v2 SVG）。
- 产品库「点位图分类 · 设备图标」筛选 chip 同步变成 v2。
- `pnpm icons:build` 重复执行结果稳定；CI 漂移测试通过；v1 目录逐字节未变。
- CAD 导出仍正常生成图块（线稿），不因 v2 失败；在计划与 ADR 0011 中注明视觉差异。
- `npx tsc --noEmit`、`npx eslint`、`npx vitest run` 通过；真实浏览器逐页验收。

## 不做

- 不删除 v1 资产（历史交付引用）。
- 不改 CAD 图块的命令集，不为图标引入填充/填充图案（客户端不支持，且会放大文件）。
- 不在本轮改动点位坐标、场景、报价或交付版本语义。
