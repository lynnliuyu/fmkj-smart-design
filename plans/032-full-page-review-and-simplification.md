Status: DONE

Scope: 登录后的全部功能页面（客户侧 17 个 + 平台管理 13 个）

## 方法

- 用本机签发的会话 cookie 在无头 Chrome 里逐页打开真实登录态页面（1440×1200，另在 1280 与手机宽度做抽样）。
- 每页记录：卡片数、按钮数、链接数、表单字段数、表格行数、文本长度、页面高度、横向溢出、重复按钮/链接文案、控制台报错；并截图。
- 截图与结构化数据：`tmp/audit/`（`report.json` + `<页面>.png`，被 Git 忽略，仅本机复核用）。
- 补充人工看图的页面：概览、项目列表、点位图、报价单编辑、客户交付、产品库、合同、工单、平台管理概览、平台产品管理、成员/权限。

## 需要先知道的三件事

1. ~~`/users` 与 `/settings/account` 是同一个页面~~ **更正**：`/users`、`/account-system` 早就是 `redirect()` 存根（分别转 `/settings/account`、`/admin/customers`），审查时看到的内容一致是跳转生效，不是重复页面。此项**无需处理**。
2. **平台管理页缺少工作台导航**（已修，见下）。
3. **平台管理页没有顶部工作台导航**：进入 `/admin/*` 后顶部栏只剩侧边栏开关，`项目 / 方案报价 / 合同`消失，与客户侧不一致。
