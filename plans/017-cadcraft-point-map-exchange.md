# Cadcraft 与点位图工作台交换

Status: COMPLETE

用户已授权在已安装的 Cadcraft 中继续建立净底、自动摆点、人工微调与返回工作台的流程。先完成本地文件闭环；产品、控制关系、场景和报价仍以工作台为准。

## 交换约定

权威合同为 `lib/point-map-cad-contract.ts`：浏览器与 Node 24 本地桥接脚本共用类型及运行时解析器，不维护两套载荷定义。每次仅交换一个已绑定 CAD 坐标窗口的楼层。底图绑定记录净底 DXF 的 SHA-256 和独立 drawingId；导出记录项目、楼层、背景摘要、交换 ID 和各点位的基线百分比坐标。

CAD 回传包含原交换清单和所有稳定 ID 的 CAD Y-up 坐标。只允许坐标更新，缺失、重复、未知 ID、跨项目/楼层/底图或超范围坐标均整包拒绝。工作台导出后另行移动过的点位会发生冲突；产品等业务字段不会被回传覆盖。已处理文件重导入为无变化。移动点位与关联场景重新待复核。

本地桥接脚本校验 DXF 摘要，输出独立衍生图；源文件不覆盖。图块使用不可见稳定 ID 与交换标识属性。回传不依据重生成的 CAD handle，不自动新增或删除设备。
